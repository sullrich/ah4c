Upgrading from a pre-Trixie image?
Press Reinstall once for every saved Vulkan or CUDA runtime. Driver packages survive container rebuilds, so packages saved by the previous Debian release need to be replaced with Trixie versions.

GPU choices appear only when this container can load them (for Vulkan: a driver and /dev/dri). The log names the device actually doing the work.

Box shows a whole caption at once, the way recorded programs look, and runs a little further behind for it. Roll-up writes words as they are recognized and scrolls finished lines up — closest to the sound, and the one to try if a box feels too slow.
