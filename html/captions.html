Closed Captions
Off

Speech is transcribed here, on this machine, and written into the video as CEA-608 caption data, the same carriage an HDHomeRun uses for over-the-air captions. Channels DVR and any other player will show it as CC1 with no sidecar file. The video itself is never re-encoded, so picture quality and tune time are unchanged.

Speech engine nothing is bundled in the image; fetch only what you want

Captions need two downloads, and this page does both. The engine is a small program that does the listening; the model, further down, is the file that actually knows how to turn speech into words. Pick a model first — each one names the engine it needs, and only that engine has to be fetched. Neither is in the ah4c image, nothing is downloaded until you ask, and every button says exactly which file it will fetch and from where.

Where the model runs. The processor build needs nothing and handles several tuners at once. A GPU build is only offered when this container can actually load it: CUDA appears once the NVIDIA container runtime is passing the driver through, Vulkan once a Vulkan driver and /dev/dri are present. Neither needs a change to the image — only to your compose file.

There are two engines and the model decides which one is used, so there is nothing to choose here. parakeet.cpp runs NVIDIA's Parakeet and Nemotron models and is about a megabyte. transcribe.cpp runs a much wider set of families, Cohere Transcribe among them, and is larger because it carries its own ggml backends rather than compiling them in. Both are downloaded here and neither is in the image. Switching between models that use different engines means one more download, once.

Both land in /opt/captions, a bind mount, so they survive a container rebuild. Remove them any time to get the space back.

Reading the labels. The percentage is how many words come out wrong on a standard test, so lower is better and 3% means roughly three words in every hundred. Types as it hears means captions appear while the person is still talking; waits for each sentence means it listens to the whole phrase first, which is more accurate but arrives later. Bigger models are generally more accurate and ask more of the machine.

Those percentages come from LibriSpeech test-clean, the one test all of these publish, so they can be compared with each other. Read them as a ranking rather than a promise: it is clean, clearly-read speech, and live television — music beds, crowd noise, people talking over each other — is harder than that for every model here. Models without a figure have no published number on that test, so they carry a rating and no measurement rather than a guess.

Caption settings

Capitals are the long-standing convention for broadcast captioning and are easier to read across a room. They also even out the streaming models, which write in lower case.

Captions appear a couple of seconds after the words are spoken, the same as live broadcast captioning, because the sentence has to finish before it can be recognized. Extra delay only pushes the text further back if you want it to line up more loosely.
