Welcome to ah4c

This proxy hands Channels DVR a video stream from your streaming devices and encoders. ah4c can start without choosing a streaming app or adding any tuners, so this short wizard is only here to make later setup easier.

Everything you set here is saved to settings.json in the container's persistent /opt/config folder, so it survives container updates and recreation. A setting supplied by your container remains in control and appears grayed out here.

A few things live outside this page by design: ports, persistent folders, graphics-device access and the image tag must be configured before the container starts. For most installs the only host-side value you need is HOST_DIR.

Your streaming-app choice tells ah4c how to prepare the device, open a channel, and stop afterward. You can choose it later because ah4c cannot safely guess which service and device you use. Tuners are optional too and can be added now or later.

You can return to any of this later under Settings; changes to tuners or the streaming app take a container restart, which the page will offer when needed.

    Addresses & time zone

    Tip: These addresses may be entered with or without a port. When no port is entered, ah4c assumes 7654 for this ah4c server and 8089 for Channels DVR. If either service uses a different port, include it in the address. For Channels DVR, open Channels in another browser tab and copy the address from its address bar. During initial setup, ah4c also suggests the time zone reported by this browser; change it if the server is somewhere else.

    Streaming app scripts

    Optional during initial setup: ah4c uses a small set of scripts to open your streaming app, switch to the requested channel, and stop playback when finished. You do not need to read or edit them. The official choices come from the scripts folder in sullrich/ah4c on GitHub.

    Browse local scripts shows choices already stored on this server. Check GitHub for scripts reads only the available folder names; it does not download every script. ah4c downloads only the choice you select, and a GitHub outage never prevents it from using a complete stored copy.

    Advanced: upload custom control files

    This is only for people providing their own controls. Name the folder, then select prebmitune.sh, bmitune.sh, and stopbmitune.sh. You may also select helper files. Nothing is saved unless all three required files are included.

    Tuners — order determines tuner numberTuners are managed by environment variables because NUMBER_TUNERS is set there. To prevent two tuner lists from conflicting, tuner editing is turned off on this page. Remove NUMBER_TUNERS and the related tuner variables from your container settings if you want to manage tuners here instead.

    Optional during setup: Add tuners now or return later. An encoder URL or CMD tells ah4c where each tuner's video comes from; these values are specific to your hardware and cannot be guessed. Choose Edit tuner order to assign the exact tuner numbers you need.

    Before saving: Android devices may show an Allow USB debugging message that must be approved on the TV. When Use pyatv is enabled, use Pair next to each Apple TV and enter the PIN shown on the television. Save setup checks every configured tuner and encoder and will not continue until they are ready.
