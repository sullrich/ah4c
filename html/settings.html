Welcome to ah4c

Welcome to ah4c. This proxy hands Channels DVR a video stream from your streaming devices and encoders. ah4c can start without a streamer script or any tuners, so this short wizard is only here to make later setup easier.

Everything you set here is saved to settings.json in the container's persistent /opt/config folder, so it survives container updates and recreation. Every setting is still an ordinary environment variable underneath: any environment variable supplied to the container always wins and appears here grayed out with a "set by environment" badge. You can mix freely — provide a few values as environment variables and manage the rest on this page.

A few things live outside this page by design: ports, persistent folders, graphics-device access and the image tag must be configured before the container starts. For most installs the only host-side value you need is HOST_DIR.

The script package is optional and can be chosen later because it is unique to your streaming app and device; ah4c cannot safely guess it. Tuners are optional too and can be added now or later.

You can return to any of this later under Settings; changes to tuners or the streamer app take a container restart, which the page will offer when needed.

Proxy & DVR

Recommended: The proxy address lets ah4c write working stream addresses into M3U files. It is requested during setup but does not block direct tuning.

Tip: The proxy address is usually the same address you use to open ah4c, without http://. For example, if you open http://192.168.1.50:7654, enter 192.168.1.50:7654. The Channels DVR host is the address of the computer running Channels DVR, which may be a different machine. You will choose a channel list later from the Channel M3Us page.

Streamer script

Optional during initial setup: The script package you choose here becomes STREAMER_APP; there is no second app setting and you do not need to supply that environment variable yourself. Leave it blank until you are ready. Check for scripts gets the valid package list from GitHub without downloading any scripts. After you select and save one, the container downloads only that package.

Tuners — order determines tuner number

Optional during setup: Add tuners now or return later. An encoder URL or CMD tells ah4c where each tuner's video comes from; these values are specific to your hardware and cannot be guessed.

NUMBER_TUNERS is set by the environment, so the complete tuner section is read-only. Mixed environment and Settings tuner lists are not supported.

No tuners are configured. ah4c can start this way. Add one now, or return to Settings from the main navigation when you have the details.
