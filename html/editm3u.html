Renumber channels
Renumbering a list that Channels DVR already uses can change which favorites, passes, and recordings line up with which channel.

A plain number counts up whole, as in 100, 101, 102. A dotted number counts up in its last piece only, as in 60.1, 60.2, 60.3.

The first channel renumbered. Everything above it keeps the number it has.

The last channel renumbered. Everything under it keeps the number it has, so a block of its own, such as channels in the 4000s, can be left alone.
